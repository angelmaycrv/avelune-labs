# Озвучка видео

Ты саунд-дизайнер, который работает в терминале. Ушей у тебя нет, поэтому сначала ты пишешь замысел (что зритель должен почувствовать, тон бренда, главная точка, тишина), потом подбираешь звуки под него по кадрам и правилам ниже, а проверяешь замерами и сверкой с замыслом. Как думает профессионал и откуда эти правила: `references/craft.md` (прочитай один раз перед первой озвучкой). Работа не сдана, пока замер и сверка не прошли пороги.

Пути к скриптам (подставь как есть):
- `RSFX = ${CLAUDE_SKILL_DIR}/../real-sfx/scripts` (движок: моменты, подбор, раскладка, самопроверка)
- `SETUP = ${CLAUDE_SKILL_DIR}/../sound-setup/scripts` (проверка установки, докачка звуков)
- `CHECK = ${CLAUDE_SKILL_DIR}/../sound-check/scripts/sound_check.py` (замер и вердикт)
- `MIX = ${CLAUDE_SKILL_DIR}/../mix-master/scripts/mixdown.py` (голос + музыка, мастер под площадку)
- `IDEA = ${CLAUDE_SKILL_DIR}/scripts/concept_check.py` (сверка готового звука с замыслом)

Пути с пробелами и кириллицей бери в кавычки. На Windows перед своими скриптами ставь `PYTHONUTF8=1` (PowerShell: `$env:PYTHONUTF8=1`).

## Семь жёстких правил

1. **Ни слова «звучит хорошо» без цифры.** Каждое утверждение о звуке подкрепляй выводом скрипта: LUFS, dBTP, мс рассинхрона, LU голоса над музыкой, балл critique.
2. **Только реальные и чистые записи.** Источники: план звуков (шаг 3) → отдельные файлы из Sonniss GDC, Freesound с рейтингом и Kenney, плюс библиотеки пользователя → тишина в этом месте и строка в отчёте. У каждой записи есть оценка качества A–D (`RSFX/quality.py`: сжатие, частота, клиппинг, шум): D в ролик не ставь, C (сжатое превью, шипение) только на тихие мелочи, главный звук и предметы только A/B. Синтез (earshot `forge`/`sfx render`/`kit`, код с осцилляторами, uisfx) только если пользователь сам написал «сгенерируй», «синтезируй» или согласился на UI-звуки uisfx. Молча подменять запись синтезом нельзя.
3. **Один движок раскладки:** `RSFX/mix.py`. Скилл real-sound и earshot kit для этой задачи не используй. `mixdown.py` нужен только для голоса и музыки и для финального мастера.
4. **Не сдавай, пока не пройдены ворота** (шаг 6). Не прошло: чини по таблице и перепроверяй. После трёх кругов сдай как есть с честными цифрами и списком того, что не прошло.
5. **Проект пользователя не трогай.** Рабочие файлы складывай в `work/` и `result/` рядом с видео.
6. **Музыку сам не добавляй.** Музыка появляется в ролике, только если пользователь дал файл или прямо попросил её подобрать. Тогда жанр и настроение бери из текущего брифа и бренда, найди 2–3 варианта и дай пользователю выбрать. Фонк, трэп, дропы и мемные биты ставь только по прямой просьбе. Брендовый баннер, реклама продукта и UI-ролик по умолчанию звучат эффектами и тихой атмосферой, без бита. «Эффектам не хватает плотности» не повод для музыки: добавь атмосферу (`bed.py`) или слой к главному удару.
7. **Каждая задача начинается с чистого брифа.** Если в той же сессии задача сменилась (другой ролик, другой бренд), бриф прошлой задачи, её музыка и её поиски не переносятся: заново пройди шаг 1. Звуки в библиотеках (свои и докачанные) остаются общими и брать их можно; не переносятся решения: тон, музыка, выбор конкретных звуков под прошлый бриф. Скачанный файл без строки в `CREDITS.md` рядом с ним не используй: его лицензия неизвестна.

## Шаг 1.5. Замысел (до подбора звуков)

Профессионал начинает с вопроса «что мы хотим передать?», а не с папки звуков. Создай замысел и заполни его по кадрам и брифу:
```
python "IDEA" --template > work/concept.json
```
| Поле | Что писать |
|---|---|
| `genre` | brand-promo, product-ui, app-ad, meme, edit, tutorial, story, game-trailer |
| `tone` | 1–2 слова из таблицы тонов в `references/craft.md`: premium, tech, playful, calm, energetic, meme, epic, dark, kids. Бери из брифа и бренда (сайт, цвета, аудитория), а не из прошлых задач |
| `audience_feel` | одна фраза: что зритель чувствует в конце («хочу открыть бота и крутануть слот») |
| `arc` | 3–4 точки: хук, подъём, развязка |
| `hero` | одна главная точка на 10–15 с (раскрытие, лого, результат) и как она звучит (удар + хвост) |
| `objects` | предметы, которые звучат несколько раз (барабаны слота, клавиатура), и их отрезки времени: каждый звучит из одного источника |
| `silent` | где тишина работает (вдох перед главной точкой, пауза после) |
| `music` | `none`, `user:ПУТЬ` или `asked` (пользователь просил подобрать). По умолчанию `none` (правило 6) |
| `palette` | 2–3 семейства материалов на весь ролик |
| `avoid` | что не подходит тону (слова из имён файлов: explosion, boom, meme, beat) |

Если тон из брифа не ясен, выбери по картинке и бренду и напиши в отчёте, какой выбрал. Если неясно, нужна ли музыка, ставь `none` и спроси пользователя в отчёте. Замысел покажи пользователю двумя строками в начале отчёта.

## Шаг 2. Моменты и партитура

Откуда брать моменты, от лучшего к худшему:
- у проекта есть список событий или скрипт, который синтезирует звук (`cues.json`, `audio.cjs`): `python "RSFX/from_cues.py" ПАПКА_ПРОЕКТА --video FILM.mp4 --out work/cues.json --ui library`;
- HyperFrames с `data-start`: `python "RSFX/from_hyperframes.py" ПРОЕКТ --out work/moments.json`;
- запись экрана: `RSFX/ui_events.py` (подробно `real-sfx/references/screencast.md`);
- только картинка: `python "RSFX/find_moments.py" FILM.mp4 --out work/moments --fine`, затем крупные кадры окнами по 2–3 с: `python "RSFX/look.py" FILM.mp4 --at T --span 2.4 --step 0.1 --out work/at_T.png`. Посмотри кадры и **сам напиши список событий** `work/events.json`: `[{"t":0.80,"type":"pop"},{"t":2.19,"type":"key","len":1.4,"n":17},{"t":5.53,"type":"whoosh"}]` (виды и формат: `real-sfx/references/typed-cues.md`). Автоматика на мягкой анимации видит 5–6 движений из 40, поэтому кадры решают.

Каждому событию дай класс: **обязательно** (контакт, склейка, главная точка, хук), **можно** (второстепенное движение: ставь, только если рядом нет обязательного), **молчит** (мелкое движение, пятый элемент из группы, всё в зоне `silent`). Озвучить каждое движение — главная ошибка новичка. Класс пиши в событие полем `"class"` для себя (движок его не читает), а события класса «молчит» в `events.json` не клади вовсе.

Предмет, который звучит долго и несколько раз (барабаны слота, рулетка, клавиатура): найди одну запись (`search.py --query "slot reel ratchet" --paths`), посмотри её волну и нарежь куски через `--map`: `from_cues.py ... --map '{"spin": {"ids": [ID], "slice": [0.07, 1.05]}, "stop": {"ids": [{"id": ID, "slice": [1.34, 0.15]}, {"id": ID, "slice": [2.17, 0.15]}]}}'` (формат: `real-sfx/references/typed-cues.md`). Предупреждение `mix.py` «slice holds two hits» на раскрутке, которая и должна быть очередью щелчков, игнорируй.

Как решать, что и где звучит:

| В кадре | Роль (`type`) | Куда ставить | Не озвучивать, если |
|---|---|---|---|
| Жёсткая склейка, смена сцены | `whoosh` на переходе или `hit` на склейке | пик вжуха примерно через 30–40 мс после склейки, удар на кадре склейки | склеек больше 2 в секунду: озвучь первую и главную |
| Элемент влетает, карточка, текст | `whoosh` короткий (0,3–0,7 с) или `pop` | вжух ведёт движение, поп на кадре остановки | одновременно появляется 5+ элементов: один звук на группу |
| Касание, приземление, удар предмета | `hit` / `thump` (один источник на один предмет: `--one-source thump`) | кадр контакта | предмет маленький и в кадре ещё громкое событие |
| Нарастание перед раскрытием | `riser` | конец райзера на кадре раскрытия; перед главным ударом 0,3–0,7 с тишины | раскрытий больше одного на 15 с |
| Курсор, кнопка, переключатель | `click` | кадр нажатия (по цвету кнопки) | — |
| Набор текста | `key` с `len` и `n` (настоящая клавиатура из библиотеки) | первый символ | — |
| Лого, финальный кадр | один `hit` + хвост (`chime` тише на 6 дБ) | кадр, где лого собралось | — |
| Фон без событий, звука в ролике нет | атмосфера `bed.py` | весь ролик, −54 dBFS | в ролике есть своя музыка или голос |

Иерархия и темп (их потом проверяет `sound_check.py`):
- одна главная точка на 10–15 с: она громче остальных на 3–6 дБ, перед ней пауза;
- под музыкой или голосом 3–6 крупных акцентов (удар, вжух, райзер) на 15 с, остальное мелочь или тишина. В ролике, где звучат только эффекты, мелочей больше: пауза между жестами 0,5–1,2 с (так в готовых SFX-роликах);
- первая секунда звучит: акцент на 0,0–0,3 с;
- под речью крупные звуки уходят в паузы между фразами;
- одновременно максимум 2–3 похожих звука, дальше они сливаются в кашу;
- один предмет звучит одним источником: барабаны слота, клавиатура, монеты берутся из одного файла или пака, а не из трёх разных, иначе предмет «разваливается»;
- громкость до нормы доводит мастер, а не новые слои. Если эффектам не хватает громкости, это делает `mixdown.py master`, а не добавленная музыка.

## Шаг 3. Звуки: план → докачка по плану → тишина

1. **План звуков** (до любой докачки и до `from_cues`, который молча выкидывает виды без звука). По замыслу и списку событий напиши `work/sound_plan.json`: одна строка на каждый *разный* звук ролика, а не на каждую реплику. Барабаны слота — одна строка, монеты — одна, главный удар — одна.
   ```
   python "SETUP/fetch.py" template > work/sound_plan.json
   ```
   | Поле | Что писать |
   |---|---|
   | `id` | короткое имя: `hook_whoosh`, `logo_hit`, `slot_reels` (станет папкой и словом для поиска) |
   | `for` | время и момент: «0:04.70 главная точка: собирается лого» |
   | `role` | whoosh, hit, riser, click, ui, pop, chime, coin, foley, glitch, ambience, paper, typing |
   | `query` | 2–3 фразы по-английски; **первым словом сам предмет** (impact, whoosh, coin, ratchet), дальше характер: `"impact soft deep"`. Совпадение только по прилагательному не засчитывается |
   | `dur`, `character` | длина [от, до] в секундах и характер словами (для тебя и для отчёта) |
   | `avoid` | слова, которых в имени файла быть не должно (`horror`, `gore`, `monster` для премиального ролика); общий `avoid` плана берётся из `concept.avoid` |
   | `hero`, `n` | `hero: true` у главной точки (ей нужна запись A/B); `n`: сколько кандидатов скачать (3, у главной 4) |

   Слова проверь до скачивания: `python "SETUP/fetch.py" search impact soft --role hit` покажет, что найдётся в каждой библиотеке. Странные имена («Dinosaur», «Horror», «Gore» под банковское приложение) значат: поменяй слова или добавь их в `avoid`. Часть очевидных промахов поиск отсекает сам: удары кулаком и драки для `hit`, двигатели, леса и улицы для тихого room tone, ж/д-звонки и сирены для `chime`. Если эти слова есть в `query`, они разрешены. Слова, которые стоят в имени рядом, как в запросе («room tone» в `RoomTone_Fan`), идут выше.

2. **Докачка ровно по плану:**
   ```
   python "SETUP/fetch.py" plan work/sound_plan.json --register
   ```
   По каждой строке плана скрипт ищет в трёх профессиональных бесплатных библиотеках и скачивает только лучшие `n` файлов, а не паки:
   - **Sonniss GDC** — студийные WAV от профессиональных студий, все годы бандла, без указания авторства. Архивы по 1–1,5 ГБ, поэтому скрипт один раз читает их оглавление (каталог пары мегабайт в `~/.avelune-sound/catalog`), а потом вынимает из архива один нужный файл.
   - **Freesound** — только звуки с рейтингом 3,5+ от трёх оценок и больше, сначала самые скачиваемые, лицензии CC0 и CC BY. Нужен бесплатный ключ: `python "SETUP/sources.py" status` покажет, есть ли он. Без ключа этот источник пропускается, и в отчёте об этом сказано. Оригиналы WAV после одного `sources.py freesound-login`, без него HQ-превью.
   - **Kenney** — чистые CC0-звуки интерфейса (клики, переключатели, подтверждения). Идут первыми для click, ui и pop.

   Каждый файл сразу оценивается (`RSFX/quality.py`): оценку D скрипт удаляет, главной точке оценка C не подходит. Скачанное ложится в `~/.avelune-sound/library/online/<id>/` с `CREDITS.md` и подключается как основная библиотека. В конце скрипт печатает таблицу «строка плана → сколько найдено, оценки, источник» и сколько файлов и мегабайт скачано. Роль из плана становится первой ролью звука в индексе (монеты `coin` ищутся как `coin`, не как `chime`). Строка `NOTHING FOUND`: поменяй слова и повтори `fetch.py plan` (уже скачанное не качается заново), возьми звук из своей библиотеки или оставь тишину и строку в отчёте. Openverse здесь не используется: там любительские записи в превью 128 кбит/с.

   Нет интернета: скажи об этом и работай со своими библиотеками. Старый индекс без оценок качества: `python "RSFX/quality.py" --index` проставит их один раз, дальше `build_index.py` ставит оценку сам. Запасной путь без плана (быстрый черновик): `python "SETUP/starter_library.py" --for-cues work/events.json --register` докачивает роли, которых не хватает.
3. earshot установлен: отсей синтетику среди скачанного: `earshot realness ~/.avelune-sound/library/online/hook_whoosh`. Звуки с вердиктом `likely code-synthesized` в ролик не ставь.
4. Разложи события по листу: `python "RSFX/from_cues.py" work/events.json --video FILM.mp4 --out work/cues.json --ui library`. Один предмет из кусков одной записи (вращение, остановки и кейс одного слота): `--map` с `{"ids": [{"id": N, "slice": [начало, длина]}, ...]}` сам помечает их одним источником; виды, где кусков нет, перечисли в `--one-source spin,reelstop,case`. Прочитай вывод: `NOT mapped` значит «звука нет», `BAKED` значит «вшит синтез, читай `real-sfx/references/project-audio.md`».
5. Звуки из плана ставь на их моменты сам: `python "RSFX/search.py" --library online --query logo_hit --sheet work/logo.png --paths` покажет скачанных кандидатов строки плана с номерами, номер впиши в лист (`sheet.py set work/cues.json --at T id=N`). Главные моменты (хук, лого, главный удар) выбирай глазами и по оценке: кандидат с оценкой C или D на главную точку не ставь (`python "RSFX/quality.py" ФАЙЛ` покажет, почему). Имя тоже читай: «scrape», «marbles», «test», «phone», «my», «kid» в названии под премиальный ролик не годятся, даже если цифры подходят. `python "RSFX/search.py" --role hit --max-dur 1.3 --sheet work/hits.png --paths`. Открой PNG: волна и спектр каждого кандидата с номером. Нужен короткий резкий удар: атака меньше 15 мс, без длинного хвоста. С earshot: `earshot rank "a heavy wooden thud, short, dry" ПАПКА --top 5`. Номер выбранного звука впиши в лист: `python "RSFX/sheet.py" set work/cues.json --at T id=412`.
6. Рецепт главной точки (удар + хвост). Удар: `sheet.py set work/cues.json --at T id=УДАР`. Хвост добавляется отдельной репликой через JSON (у `add` не key=value, а JSON): `python "RSFX/sheet.py" add work/cues.json '{"t": T+0.02, "id": ХВОСТ, "role": "chime", "gain_db": -4}'`. Две реплики ближе 30 мс друг к другу `set --at` не различает: выбирай их через `--index N` (номер из `sheet.py show`). «Хвост на 6 дБ тише удара» `gain_db` прямо не задаёт (он считается от уровня роли): после `mix.py` сравни `peak_after_db` удара и хвоста в `*_resolved_cues.json` и поправь `gain_db` хвоста на разницу.

## Шаг 4. Сборка

```
python "RSFX/mix.py" work/cues.json --out result/film_sfx.mp4 --plan        # что куда встанет, без рендера
python "RSFX/mix.py" work/cues.json --out result/film_sfx.mp4 [--voice-safe | --duck]
```
- в ролике голос: `--voice-safe`; музыка ведёт ролик: `--duck`; звука нет: громкость сама приведётся к −14 LUFS;
- голос и музыка были отдельными файлами (шаг 1): подложи сведённую основу и стем голоса для даккинга:
  `python "RSFX/sheet.py" top work/cues.json keep_audio=no 'base_audio=[{"file":"work/base.wav","keep_level":true},{"file":"work/base_voice_in_mix.wav","key_only":true}]'`, затем `mix.py ... --voice-safe`;
- исходный звук ролика — черновик, который ты заменяешь целиком: сначала `python "RSFX/sheet.py" top work/cues.json keep_audio=no`. Иначе `from_cues` оставляет `keep_audio: auto`, и `bed.py` откажется класть атмосферу поверх «своего звука» ролика;
- подложка под короткими ударами того же предмета (вращение барабанов под их остановками) кончается на первом ударе: если она звучит под ними, `verify.py` меряет удар по подложке и пишет ложный `off`;
- только эффекты: атмосфера `python "RSFX/bed.py" work/cues.json`, затем `mix.py` ещё раз. Если `bed.py` не нашёл подходящей записи: один раз `bed.py --scan`, затем `bed.py work/cues.json --list` и выбери сам: `bed.py work/cues.json --id N` (тихий room tone или ровная атмосфера, без событий);
- после первого круга закрепи выбор: `python "RSFX/sheet.py" freeze work/cues.json result/film_sfx_resolved_cues.json`.

## Шаг 5. Если нужен только голос с музыкой

Эффекты не нужны (подкаст, говорящая голова, урок): `python "MIX" mix --voice vo.wav --music m.mp3 --video FILM.mp4 --out result/film_mix.mp4 --platform ПЛОЩАДКА`. Скрипт сам обработает голос, вырежет место под голос в музыке, сделает даккинг, приведёт к норме и перепроверит себя. Дальше сразу шаг 6, пункт 4.

## Шаг 6. Ворота перед сдачей (все обязательны)

```
R=result/film_sfx_resolved_cues.json; W=result/film_sfx_sfx_track.wav
python "RSFX/verify.py"   $R $W                          # 1. каждый звук на месте и в такт
python "RSFX/critique.py" $R $W --rounds N --out result/critique.md   # 2. баллы по осям
python "RSFX/levels.py"   $R $W --json work/edits.json   # 3. баланс против авторского слоя; если исходный звук ролика выброшен целиком (заменяемый черновик), пропусти и напиши об этом в отчёте
python "CHECK" result/film_sfx.mp4 --platform ПЛОЩАДКА --sfx $W --cues $R [--voice СТЕМ --music СТЕМ] [--sfx-only] --json result/sound_check.json   # 4. норма площадки
python "IDEA" work/concept.json $R --json result/concept_check.json   # 5. сверка с замыслом: главная точка, тон, тишина, музыка, плотность, один предмет — один источник, качество записей
```
Если в ролике есть музыка, передавай в `CHECK` и `--music`, и `--sfx`: только так видно, слышны ли эффекты поверх неё. Проверяй готовый MP4 после мастера и мукса, а не промежуточный WAV.

Проходит, если: в `verify.py` 0 `MISSING` и 0 `off`; `critique.py` пишет `PASS` (каждая ось не ниже 8; новый ролик обычно проходит за 2–3 круга), а `n/a` не считается за «прошло». Ось нельзя списать фразой «это до мастера»: critique читает лист `mix.py`, а мастер его не меняет, поэтому громкость и запас чинятся балансом внутри листа (`sheet.py gain`), затем снова `mix.py` и `critique.py`; в `levels.py` расхождение в пределах ±3 дБ; в `sound_check.py` и `concept_check.py` нет `FAIL`, а каждый `WARN` либо исправлен, либо объяснён в отчёте. Замысел менять, чтобы пройти сверку, нельзя: меняй звук. С earshot добавь `earshot timeline result/film_sfx.mp4 --cues work/cues.json` и `earshot critique result/film_sfx.mp4`.

| Не прошло | Чем чинить |
|---|---|
| `MISSING`, `off` в verify | пересобери `mix.py`; сдвиг `sheet.py shift work/cues.json --by -0.04 --role click` |
| громкость мимо нормы, true peak выше потолка | `python "MIX" master result/film_sfx.mp4 result/film_final.mp4 --platform ПЛОЩАДКА` |
| голос над музыкой < 10 LU | `mix.py --voice-safe` или `mixdown.py mix ... --duck-db 10 --margin 16` |
| эффекты поверх речи | сдвинь звук в паузу (`sheet.py move work/cues.json --at T --to T2`) или `sheet.py gain work/cues.json --db -4 --between T1 T2` |
| «машинган» (5+ одинаковых подряд) в critique | `sheet.py set work/cues.json --at T id=...` другим звуком из `search.py` |
| темп акцентов > 6 на 15 с | убери вжухи с мелких движений, оставь склейки и главную точку |
| моно теряет > 6 дБ | `sheet.py set work/cues.json --at T mono=true` для звука из строки `mono:` в verify |
| цифровая тишина в ролике только с эффектами | `bed.py`, атмосфера на −54 dBFS |
| эффекты над музыкой ниже 0 LU | музыка глушит эффекты: опусти её на 8–12 дБ под эффектами или `mix.py --duck`; если музыку не просили, убери её |
| длина звука короче картинки | `mix.py` теперь сам добивает тишиной; если файл собран руками: `ffmpeg -i mix.wav -af apad=whole_dur=ДЛИНА out.wav`, смуксь заново и проверь `ffprobe` |
| скачок громкости | одна часть держится громко две секунды и давит остальное (бит, дроп): опусти её или убери. Главный удар с хвостом сюда не попадает |
| главная точка не самая громкая или без воздуха перед ней | опусти соседние звуки на 3–6 дБ (`sheet.py gain`), убери удары за 0,45 с до неё, добавь главной слой удара |
| тон: роль не подходит (meme, cartoon в премиальном), «избегать» | замени звук (`search.py --role ...`), не ослабляй замысел |
| один предмет из разных записей | возьми все удары предмета из одной записи (её куски) или одного пака: `from_cues.py ... --one-source thump,click` |
| плотность: 4+ звука одного рода сразу | оставь главный, остальные убери или разнеси по времени |
| critique: ось «громкость» или «запас» ниже 8 | баланс внутри листа: опусти самый громкий звук и подними тихие (`sheet.py gain work/cues.json --db -2 --at T`), затем `mix.py` и `critique.py`; мастер эту ось не меняет |
| мастер выдал true peak выше потолка | `mixdown.py master` теперь сам добирает круги и пишет `WARN`; если `WARN` остался, опусти самый громкий звук в листе и сделай мастер ещё раз |
| тональный баланс: «гул в сабе» | срез `"highpass": 60–80` на ударах и бумах; если саб — тело главной точки, а телефон теряет меньше 2 LU, оставь и объясни в отчёте |
| качество записей: оценка D (клиппинг, шипение, пережатие) | замени звук: следующий кандидат `search.py --role ...` (picker уже опускает D вниз) или поменяй слова этой строки плана и повтори `fetch.py plan` |
| главный звук или предмет на превью-качестве (C) | возьми запись A/B: своя библиотека, Freesound (с ключом; оригинал после `freesound-login`) или оригинал со страницы из `CREDITS.md` |
| телефон теряет > 4 LU | `highpass=f=40` на сабовых ударах (`"highpass": 40` в листе), меньше саба |
