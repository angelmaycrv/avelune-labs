# Сведение и мастеринг

Скрипт `MIX = ${CLAUDE_SKILL_DIR}/scripts/mixdown.py` делает всё ниже сам и в конце запускает `sound_check.py`. Эффекты по кадрам ставит не он, а `real-sfx` (вход через скилл `video-sound`). Этот скрипт получает их готовой дорожкой через `--sfx`.

## Быстрый путь

```
# голос + музыка (+ эффекты) -> mp4 под площадку
python "MIX" mix --voice vo.wav --music music.mp3 [--sfx sfx_track.wav] --video film.mp4 --out result/film_mix.mp4 --platform social
# только довести готовый микс до нормы
python "MIX" master mix.wav result/mix_master.wav --platform podcast
```
Скрипт сохраняет `*_voice_in_mix.wav`, `*_music_in_mix.wav` (стемы на уровне мастера) и `*_report.json` с вердиктом.

## Что делает `mix` и почему

| Шаг | Цепочка ffmpeg | Число, к которому стремимся |
|---|---|---|
| Голос `--voice-chain light` (по умолчанию) | `highpass=f=80,acompressor=threshold=-22dB:ratio=3:attack=8:release=120:makeup=1` | голос ровный, без гула ниже 80 Гц |
| Голос `clean` (шум, свист на «с») | + `afftdn=nr=10:nf=-45,deesser=i=0.3` | шум комнаты ниже на ~10 дБ |
| Уровень голоса до мастера | `volume` до −18 LUFS | запас под музыку и эффекты |
| Место под голос в музыке | `equalizer=f=3000:t=q:w=1:g=-3` (`--carve-db`) | 2–4 кГц музыки на 3 дБ тише |
| Уровень музыки | постоянное усиление | во время речи на `--margin` 15 LU тише голоса (рабочий диапазон 12–20) |
| Даккинг | кривая громкости по активности голоса, `amultiply`: −8 дБ (`--duck-db`), открывается за 120 мс до фразы, восстановление 350 мс | в паузах музыка дышит, под словами уходит |
| Самопроверка | меряет голос над музыкой и поправляет уровень музыки, до 3 кругов | отклонение не больше ±1 LU |
| Мастер | одно усиление до нормы + лимитер на 4× передискретизации у потолка true peak; замер уже после AAC и поправка, до 4 кругов | норма ±0,3 LU, true peak не выше потолка |

## Когда что менять

- Голос всё ещё тонет (в `sound_check` «голос над музыкой» меньше 10 LU, или пользователь просит громче): `--margin 18 --duck-db 10`.
- Музыка «проваливается» и дёргается: `--duck-db 5 --margin 13`.
- Голос шумный, свистит на «с» и «ш»: `--voice-chain clean`. Сильный шум ffmpeg не вытащит: скажи об этом прямо.
- Голос начинается не с нуля: `--voice-at 1.5`, музыка: `--music-at 0`.
- Мастер пишет «the limiter takes up to N dB», и N больше 6: в миксе один пик торчит (удар, бум). Опусти именно этот звук, а не весь микс. В редком ролике лучше честно принять −15…−16 LUFS, чем передавить лимитер.

## Ручные рецепты (когда скрипта мало)

```
# замер: интегральная громкость, LRA, true peak
ffmpeg -nostats -i IN -af ebur128=peak=true -f null -
# даккинг классическим сайдчейном (музыка = вход 0, голос = вход 1)
ffmpeg -i music.wav -i vo.wav -filter_complex "[1]asplit[sc][v];[0][sc]sidechaincompress=threshold=0.02:ratio=6:attack=20:release=350[m];[m][v]amix=2:normalize=0" out.wav
# нормализация в один проход (быстро, менее точно, чем mixdown.py master)
ffmpeg -i IN -af loudnorm=I=-14:TP=-1:LRA=11 OUT
# реверберация коротким залом (для сухого голоса в сцене): уровень хвоста −18…−24 дБ под голосом
ffmpeg -i vo.wav -af "aecho=0.8:0.7:40|70:0.25|0.15" vo_room.wav
```
После любого ручного шага запусти `python "${CLAUDE_SKILL_DIR}/../sound-check/scripts/sound_check.py" OUT --platform ПЛОЩАДКА`.

## Сдача

Цифры из `sound_check` (громкость, true peak, голос над музыкой, телефон, моно) и 3 места для прослушивания: первая фраза, самое громкое место музыки под речью и финал. Если по замеру прошло, а пользователю не нравится, верь пользователю: измени одну вещь и сравни через `sound_check.py --ab`.
