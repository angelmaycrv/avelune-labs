<h1 align="center">Avelune CEO</h1>
<p align="center"><b>Руководитель</b> · 22 скилла · часть набора <a href="../../README.md">Avelune Labs</a></p>

Штаб руководителя: стратегия и цели, юнит-экономика, финмодель, цены, найм, переговоры, регламенты. Здесь же совет директоров из 12 агентов, надзор координатора за агентами и дирижёр `avelune`, который собирает цепочку из скиллов всех семи плагинов.

**Совет директоров.** Скилл `board` запускает 12 независимых агентов: финансовый директор, маркетинг, продукт, продажи, операции, технологии, данные, юрист, бренд, голос клиента, риск-менеджер и независимый директор. Каждый голосует отдельно и не видит мнения других; итог показывает, единогласное решение или нет, и где разногласия.

**Надзор за агентами.** Хуки плагина при старте сессии и после каждого запуска агента напоминают координатору проверить результат по брифу. Порядок приёмки в скилле `supervisor`.

## Установка

```text
/plugin marketplace add angelmaycrv/avelune-labs
/plugin install avelune-ceo@avelune-labs
```

## Как пользоваться

Опишите задачу своими словами, Claude сам выберет подходящий скилл:

- «Посчитай юнит-экономику кофейни: средний чек 420 ₽, себестоимость 30%, аренда 180 тыс.»
- «Собери совет директоров: стоит ли открывать вторую точку в соседнем районе?»
- «Запусти продвижение стоматологии на ноябрь, бюджет 150 тысяч»

Или вызовите скилл напрямую: `/avelune-ceo:avelune …`

## Скиллы

| Скилл | Что делает |
|-------|-----------|
| [`avelune`](skills/avelune/SKILL.md) | Дирижёр всех плагинов Avelune Labs. Принимает большую задачу одной фразой («запусти продвижение на месяц», «нет заявок», «открываем вторую точку», «запускаем курс»), разбивает её на шаги, выбирает нужные скиллы из семи плагинов, задаёт порядок, передаёт… |
| [`board`](skills/board/SKILL.md) | Совет директоров из 12 агентов. Решение или идея рассматривается независимо финансами, маркетингом, продуктом, технологиями, продажами, юристом, операциями, данными, брендом, голосом клиента, риск-менеджером и инвестором-стратегом. |
| [`brainstorm`](skills/brainstorm/SKILL.md) | Мозговой штурм по любой задаче: 30–50 идей разными техниками (SCAMPER, обратный штурм, морфологический ящик, аналогии, ограничения) и отбор лучших по ICE. |
| [`delegation`](skills/delegation/SKILL.md) | Превращает задачу в понятное техническое задание для сотрудника, подрядчика, фрилансера или ИИ-агента: цель, результат, критерии приёмки, сроки, бюджет, примеры. |
| [`finmodel`](skills/finmodel/SKILL.md) | Финансовая модель на 12 месяцев: выручка, расходы, прибыль, движение денег, точка безубыточности, три сценария и предупреждение о кассовом разрыве. |
| [`focus-week`](skills/focus-week/SKILL.md) | Планирование недели руководителя: разбор всех дел, приоритеты по важности и влиянию, что делегировать, что выбросить, блоки глубокой работы в календаре. |
| [`grants`](skills/grants/SKILL.md) | Поиск и подготовка заявок на гранты, субсидии, акселераторы и конкурсы для малого бизнеса, IT-проектов, социальных и культурных проектов в России. |
| [`hiring`](skills/hiring/SKILL.md) | Найм сотрудника или подрядчика: карта роли с результатами, текст вакансии, структурированное интервью, тестовое задание, проверка рекомендаций, шкала оценки. |
| [`meeting-notes`](skills/meeting-notes/SKILL.md) | Протокол встречи из заметок, расшифровки или записи: решения, задачи с владельцами и сроками, открытые вопросы, письмо участникам. |
| [`negotiation`](skills/negotiation/SKILL.md) | Подготовка к переговорам и ведение их: цели, лучшая альтернатива (BATNA), зона согласия, якорь, уступки, калиброванные вопросы, фразы для трудных моментов. |
| [`onboarding`](skills/onboarding/SKILL.md) | План ввода нового сотрудника или подрядчика в работу: первый день, первая неделя, 30-60-90 дней, доступы, наставник, первая победа. |
| [`partner-letters`](skills/partner-letters/SKILL.md) | Письма и сообщения партнёрам, блогерам, СМИ, поставщикам и клиентам: холодное письмо, предложение о сотрудничестве, напоминание без ответа, ответ на предложение, отказ, благодарность. |
| [`pitch`](skills/pitch/SKILL.md) | Питч и презентация для инвестора, акселератора, конкурса, партнёра или крупного клиента: структура из 10–12 слайдов, текст каждого слайда, ключевые цифры, речь на 3 и 10 минут, ответы на трудные вопросы. |
| [`playbooks`](skills/playbooks/SKILL.md) | Регламенты, инструкции и чек-листы, чтобы работа шла одинаково хорошо без постоянного участия руководителя. |
| [`postmortem`](skills/postmortem/SKILL.md) | Разбор неудачи без поиска виноватых: что случилось, почему, что меняем, чтобы не повторилось. |
| [`pricing`](skills/pricing/SKILL.md) | Цены и тарифы. Определяет цену через ценность для клиента, строит линейку тарифов, планирует повышение цены без потери клиентов, пишет текст анонса. |
| [`proposal`](skills/proposal/SKILL.md) | Коммерческое предложение под конкретного клиента: проблема клиента, решение, результат в цифрах, пакеты и цены, доказательства, следующий шаг. |
| [`risk-map`](skills/risk-map/SKILL.md) | Карта рисков бизнеса или проекта: что может пойти не так, вероятность и ущерб, ранние сигналы, план Б и страховка. |
| [`strategy-okr`](skills/strategy-okr/SKILL.md) | Стратегия и цели на квартал или год. Ставит диагноз, выбирает главное направление, превращает его в OKR и дорожную карту, отсекает лишнее. |
| [`supervisor`](skills/supervisor/SKILL.md) | Режим надзора координатора за агентами. Координатор ставит агентам задачи с критериями приёмки, следит за всеми работающими агентами, проверяет каждый результат по брифу и сразу поправляет агента, если он ушёл в сторону, выдумал факт или сделал не по формату. |
| [`unit-economics`](skills/unit-economics/SKILL.md) | Юнит-экономика бизнеса и каналов. Считает CAC, LTV, маржу, срок окупаемости клиента, отток, вклад каналов и показывает, какой рычаг исправит экономику. |
| [`weekly-brief`](skills/weekly-brief/SKILL.md) | Еженедельная сводка для руководителя на одну страницу: цифры против плана, победы, пожары, решения, которые нужны от руководителя. |
