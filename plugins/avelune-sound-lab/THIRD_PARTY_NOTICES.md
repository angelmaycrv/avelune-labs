# Сторонние компоненты

Плагин `avelune-sound-lab` включает скилл `skills/real-sound` из проекта [Leonxlnx/earshot](https://github.com/Leonxlnx/earshot/tree/main/skills/real-sound) (автор Leon Lin, коммит `4ac3d2a` от 06.11.2026, лицензия MIT). Изменено только описание во frontmatter и добавлен `disable-model-invocation: true`: скилл запускается вручную, чтобы не спорить с `avelune-sound:video-sound`. Для работы нужен установленный earshot (см. `avelune-sound:sound-setup`).
