<h1 align="center">Avelune Creative</h1>
<p align="center"><b>Креатив и тексты</b> · 20 скиллов · часть набора <a href="../../README.md">Avelune Labs</a></p>

Креатив уровня сильного агентства. Каждый скилл опирается на книги и разборы настоящих кампаний: от «Think Small» Volkswagen до «Фрод-рулетки» Т-Банка, всего 33 кейса в базе креативного директора. Общий блок правил запрещает штампы нейросетей и требует конкретики вместо общих слов.

**Как думает сильный автор.** Во всех скиллах одинаковые правила: конкретная деталь вместо прилагательного, одна мысль на текст, правда о продукте, проверка на запрещённые штампы («не просто X, а Y», «в современном мире», «уникальный»).

## Установка

```text
/plugin marketplace add angelmaycrv/avelune-labs
/plugin install avelune-creative@avelune-labs
```

## Как пользоваться

Опишите задачу своими словами, Claude сам выберет подходящий скилл:

- «Придумай большую идею кампании для сети химчисток, бюджет небольшой»
- «Напиши 20 хуков для роликов про ремонт ванной»
- «Отредактируй текст лендинга, убери штампы и воду»

Или вызовите скилл напрямую: `/avelune-creative:brand-story …`

## Скиллы

| Скилл | Что делает |
|-------|-----------|
| [`brand-story`](skills/brand-story/SKILL.md) | История бренда и основателя. Находит правдивый сюжет компании и упаковывает его для страницы «О нас», выступления, интервью, питча, серии постов. |
| [`brand-voice`](skills/brand-voice/SKILL.md) | Голос бренда. Создаёт гайд по тону: характер бренда, шкалы тона, тон по ситуациям, словарь «говорим / не говорим», правила обращения, эмодзи и пунктуации, примеры «было / стало». |
| [`case-studies`](skills/case-studies/SKILL.md) | Кейсы клиентов. Готовит вопросы для интервью с клиентом, вытаскивает историю «было → сделали → стало» с цифрами и цитатами, пишет кейс в нужном формате: статья, пост, карусель, видео, слайд для продаж. |
| [`cover-text`](skills/cover-text/SKILL.md) | Тексты и идеи обложек (превью) для YouTube, Rutube, VK Видео, Дзена, Reels, Shorts, TikTok и каруселей. |
| [`creative-director`](skills/creative-director/SKILL.md) | Креативный директор. Ищет инсайт и большую идею для кампании или запуска, чтобы о бренде заговорили, разворачивает её в ролик, наружку, соцсети, PR и спецпроект. |
| [`creative-review`](skills/creative-review/SKILL.md) | Проверка креатива перед публикацией. Оценивает пост, ролик, баннер, сценарий или рекламу по 12 критериям (заметность, понятность, одна мысль, неожиданность, доверие, эмоция, связь с брендом, призыв, площадка, закон, желание поделиться), ставит баллы, называет… |
| [`director`](skills/director/SKILL.md) | Режиссёр и оператор. Превращает идею в ролик, который можно снять: концепция, раскадровка по секундам, планы, ракурсы, движение камеры, свет, звук, монтаж, съёмка на телефон, промпты для ИИ-видео. |
| [`editor`](skills/editor/SKILL.md) | Редактор. Сокращает, упрощает и оживляет текст: убирает канцелярит, штампы, воду, признаки текста от ИИ, выстраивает структуру, проверяет факты, орфографию и типографику. |
| [`headlines`](skills/headlines/SKILL.md) | Заголовки для статей, лендингов, писем, рекламы, превью и постов. |
| [`hooks`](skills/hooks/SKILL.md) | Хуки, то есть первые 1–3 секунды ролика или первая строка текста, которые останавливают прокрутку. |
| [`landing-copy`](skills/landing-copy/SKILL.md) | Текст продающего лендинга или страницы продукта по блокам: первый экран, проблема, решение, как работает, доказательства, цены, возражения, призыв. |
| [`memes-trends`](skills/memes-trends/SKILL.md) | Мемы, тренды и ситуативный маркетинг. Оценивает, стоит ли бренду подхватывать мем, тренд или новость, находит связь с продуктом, пишет 3–5 вариантов поста или ролика, проверяет риски (стоп-темы, права на картинки, закон). |
| [`naming`](skills/naming/SKILL.md) | Нейминг. Придумывает названия для компании, продукта, тарифа, рубрики, акции, события: 50–100 вариантов разных типов, отбор по тестам SMILE и SCRATCH, проверка домена, товарного знака в ФИПС, звучания на других языках. |
| [`offer`](skills/offer/SKILL.md) | Оффер, то есть предложение, от которого трудно отказаться: что получает клиент, за сколько, почему сейчас, почему без риска. |
| [`platform-copy`](skills/platform-copy/SKILL.md) | Копирайтер под площадки. Один смысл превращается в готовые тексты для VK, Telegram, Дзена, YouTube, Rutube, VK Видео, TikTok, Reels, Shorts, Max, сайта и рассылки с учётом лимитов, культуры и кликабельности ссылок каждой площадки. |
| [`reels-script`](skills/reels-script/SKILL.md) | Сценарий короткого вертикального ролика (Reels, Shorts, TikTok, VK Клипы) на 7–60 секунд. |
| [`repurpose`](skills/repurpose/SKILL.md) | Перепаковка контента. Из одного большого материала (подкаст, эфир, вебинар, интервью, статья, выступление) делает 20+ единиц контента для разных площадок: клипы, карусели, посты, цитаты, статью, рассылку, чек-лист, и раскладывает их по календарю. |
| [`rubrics`](skills/rubrics/SKILL.md) | Рубрики для блога, канала или аккаунта бренда. |
| [`slogans`](skills/slogans/SKILL.md) | Слоганы и девизы бренда, подписи к логотипу, слоганы кампаний. |
| [`storyteller`](skills/storyteller/SKILL.md) | Сценарист. Придумывает свежие сюжеты, премисы и повороты, строит историю по битам и сценам, пишет диалоги, планирует серии роликов с героями. |
