<h1 align="center">Avelune SMM</h1>
<p align="center"><b>SMM</b> · 20 скиллов · часть набора <a href="../../README.md">Avelune Labs</a></p>

SMM для площадок, которыми пользуются в России: Telegram, VK, Дзен, Rutube, VK Видео и другие. Контент-план с выгрузкой в CSV для любого планировщика, календарь инфоповодов, аудит аккаунта на 48 пунктов, работа с негативом, блогеры и посевы с учётом реестра и маркировки.

**Факты с датой.** Правила и функции площадок в скиллах подписаны источником и датой проверки (ноябрь 2026). Площадки меняются, поэтому каждый скилл просит сверить актуальное.

## Установка

```text
/plugin marketplace add angelmaycrv/avelune-labs
/plugin install avelune-smm@avelune-labs
```

## Как пользоваться

Опишите задачу своими словами, Claude сам выберет подходящий скилл:

- «Сделай контент-план на декабрь для Telegram и VK студии йоги»
- «Проведи аудит нашего VK-сообщества»
- «Как ответить на гневный отзыв в комментариях?»

Или вызовите скилл напрямую: `/avelune-smm:account-audit …`
