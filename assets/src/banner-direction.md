# Баннер README: направление «Бриф»

Метод: astudio-aio (контракт направления, правила баннера, линтер, критика) и ui-ux-pro-max (стиль AI-Native UI и минимализм, схема «запрос и готовый план»).

- Поверхность: обложка README и превью для соцсетей, 1280×640, безопасная зона по центру 1100×530.
- Идея: баннер показывает, как работает агентство. Пользователь пишет задачу одной фразой, дирижёр отвечает планом из пяти настоящих скиллов (цепочка «Нет заявок» из `avelune-ceo:avelune`).
- Цвет: холодный серый #EDEFF3, чернила #14161B, один акцент кобальт #1D3FD8 (действие, вопрос пользователя, текущий шаг).
- Тёмная тема: фон #121722 (сине-серый, чтобы баннер читался панелью на тёмном GitHub #0d1117), карточка #1A2030, текст #EEF1F6, кнопки #2F52F0, знак #7891FF. README подставляет её через `<picture>` и `prefers-color-scheme: dark`.
- Шрифты: Wix Madefor Display 800 (заголовок, знак) и Golos Text 400–700 (текст), оба с кириллицей.
- Знак: полумесяц, «lune» в названии Avelune.
- Первый экран: слева знак, заголовок в две строки, подзаголовок, команда установки; справа карточка диалога с планом и полем ответа.
- Другие варианты: `banner-variants.py` (таблица 101, стикерпак, совет директоров, лайнап) и `banner-phases.py` (фазы луны).

Рендер: `python3 banner.py && node <astudio-aio>/scripts/render.cjs element brief.html --selector ".banner" --out out/banner.png --scale 2 --width 1400 --height 800`.
